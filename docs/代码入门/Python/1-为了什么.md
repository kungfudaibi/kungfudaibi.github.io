# Python 入门总集

## 为了什么？

学习一门程序设计语言，最重要的是找一个明确的目标。这个目标必须明确，是一个完全清晰的目标。它不需要你知道应该如何完成，太复杂也没关系，只需要清晰明了。

举个例子，如果你的目标是：“应付考试”，那不行。一定是应付那一场、什么样的考试。比如说：“我要应付蓝桥杯2026年Python初赛”，这就没问题了。

再举一个复杂一点的例子，如果你的目标是：“做游戏”，那也不行。你要在学之前策划好完整的游戏内容，有清晰的游戏规划、故事背景、角色设定、游戏内容等等。如果可以编写一部分的任务台词、幻想一定的界面设计，那就再好不过了，也许你没有足够的资源，比如一些音效资源不够、一些角色没有脸，那也没关系，至少你知道你要的那个东西，而且那个东西已经被你在脑子里面描述出来了，这就足够了。

好了，现在请找到你自己的目标，我们才能开始学习。

你也可以在下面评论群留下自己的目标，这也是一个不错的选择。值得注意的是，一定要清晰。请不要考虑自己是否有这个能力，因为你来学编程，就是为了使自己获得这个能力的，对吧？

## 如何选择

当你找到一个明确的目标之后，请将它说给一个比较熟悉计算机的人，可以是咱们开源协会的群友。然后让其帮你选择一个合适的语言。

语言的选择，应该有下面几个方面考虑：

1. 语言特性是否满足你的需求
    
    比如，你想要做游戏开发，那么可能 C、C++、Go、Basic 这类偏基础的语言可能并不适合。像是 Python，则取决于你想要做的游戏类型。如果是简单的小游戏，像是类似心跳文学社、逆转裁判、别踩白块、跳舞的线这类的，那么 Python 适合。
    
    如果是大型游戏，那么则需要一款成熟的游戏引擎；如果是需要在安卓设备上运行，则可能需要 Java、Kotlin 等语言。

    如果你只是想要参加算法竞赛，或者应付考试，那么 C++ 更好。

    如果你想开发网站，那学 HTTP、CSS、JavaScript 之类的语言（？）更适合。

    如果你有信仰，那请遵循你的信仰。

2. 语言本身是否易学

    你是一个初学者、还是已经掌握了一门语言、还是已经完全有经验了？一门语言对你是否易学，也是一个选择语言的因素。如果你是初学者，那么类似 Kotlin 安卓开发、Dart 跨平台应用这类需要一定程度的配置的语言和开发场景，可能并不适合你；上来就直接怼汇编语言，也确实有很大的难度。

3. 语言的适用面是否广泛

    有一些语言，比如 PASCAL、COBOL、A、Visual Basic 已经接近过时了，尽管在世界的角落里总能看见它们的身影，但新世纪的我们真的要去学这样一个既不对未来的开发有帮助、又不对未来的学业有帮助、还不对未来的工作有帮助的语言吗？想想还是算了吧，不要虚度年华、浪费光阴。

    还有一些语言，其创造的目的就是为了炫技和玩乐，比如 BrainFuck、文言。除非其满足第一条你的需要、以及满足第二条，你不是初学者，这门语言学起来轻而易举；否则，请不要学。

差不多，我现在能想到的暂时就这三点，等你思考过后，再来看看我接下来说的 Python 语言在这三点上面的特征。

首先，Python 语言适用于简单脚本、日常小任务、机器学习、人工智能、简单的互联网功能。如果你需要处理班级人员数据、批量修改文件名称、批量处理图片、学习如何训练一个专用人工智能模型、构建简单的网络页面、编写简单的益智小游戏，那么 Python 相对比较适合你。

其次，这门语言是相当容易学习的，曾经人工智能没有出现的时候，很多小学将 Python 纳入了课后兴趣班的课程中，由此可见一斑。不过，说句题外话，笔者上小学的时候，在兴趣班上学的还是 PASCAL 语言，真是时过境迁啊。

最次，这门语言在如今人工智能发展的场景下，已经非常流行了，很多公司都在使用 Python 语言跑人工智能模型；另外，作为一门好用的解释性语言，有大量的系统环境工具是用 Python 语言开发的；同时，Python 还是一个通用的脚本语言，有很多大型工业化项目，需要使用 Python 作为插件解释器。

好了，以上就是劝退你的理由。该退退，后面就是深渊，不准回头了。
